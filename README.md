# لجستیک (Logistics)

سامانه هوشمند مدیریت حمل‌ونقل بار جاده‌ای — اپلیکیشن موبایل Flutter برای اتصال **رانندگان** و **متصدیان حمل‌ونقل**.

## ویژگی‌ها

### راننده
- صفحه خانه با خلاصه وضعیت و دسترسی سریع
- مشاهده بارهای متناسب با نوع بارگیر
- پیشنهاد بارهای نزدیک با GPS
- پذیرش بار و مدیریت ماموریت‌های فعال/تکمیل‌شده
- مسیریابی تا مبدا و مقصد
- ثبت اطلاعات خودرو (پلاک، مدل، نوع بارگیر، ظرفیت)

### متصدی حمل‌ونقل
- صفحه خانه با آمار بار و راننده
- مدیریت لیست بارها و وضعیت هر بار
- ثبت بار جدید با برآورد قیمت
- مشاهده جزئیات بار و راننده تخصیص‌یافته
- لیست رانندگان فعال و رانندگان نزدیک مبدا

### عمومی
- ورود و ثبت‌نام با انتخاب نقش کاربری
- ورود سریع با **اثر انگشت / پین / الگوی** دستگاه
- پشتیبانی از **فارسی** و **انگلیسی** (رابط کاربری)
- **حالت تاریک** با ذخیره تنظیمات
- منوی کناری: تنظیمات، تغییر رمز عبور، راهنما، پشتیبانی، درباره ما، خروج

## فناوری‌ها

| مورد | کتابخانه / ابزار |
|------|------------------|
| فریم‌ورک | Flutter 3.11+ |
| مسیریابی | go_router |
| مدیریت وضعیت | provider |
| ذخیره تنظیمات | shared_preferences |
| فونت | محلی: Vazir / Inter / Nasalization (بدون Google Fonts) |
| چندزبانه | flutter_localizations + AppLocalizations |
| نقشه و مسیریابی | Neshan MapLibre SDK (`org.neshan.maplibre`) + flutter_map fallback |
| موقعیت مکانی | geolocator |

## پیش‌نیازها

- [Flutter SDK](https://docs.flutter.dev/get-started/install) نسخه ۳.۱۱ یا بالاتر
- Android Studio / VS Code با افزونه Flutter
- برای اجرا روی اندروید: Android SDK و یک دستگاه یا شبیه‌ساز

## نصب و اجرا

```bash
# کلون پروژه
git clone <repository-url>
cd logistics

# دریافت وابستگی‌ها
flutter pub get

# اجرا (دستگاه متصل یا شبیه‌ساز)
flutter run
```

برای اجرا روی پلتفرم خاص:

```bash
flutter run -d linux
flutter run -d chrome
```

## ساختار پروژه

```
lib/
├── app/              # تنظیمات اپ و مسیریابی (router)
├── core/             # تم، ویجت‌های مشترک، ثابت‌ها
├── features/
│   ├── auth/         # ورود و ثبت‌نام
│   ├── driver/       # صفحات راننده
│   ├── coordinator/  # صفحات متصدی
│   ├── shared/       # پروفایل، تنظیمات، منو
│   └── splash/       # صفحه آغازین
├── l10n/             # ترجمه‌های فارسی و انگلیسی
├── models/           # مدل‌های داده
└── services/         # سرویس‌های mock (احراز هویت، بار، تنظیمات)
```

## داده‌های نمونه و آمادگی API

فعلاً `USE_MOCK_API=true` است و داده از mock می‌آید. مدل‌ها (`fromJson`/`toJson`)، `ApiClient` با JWT، و مسیرهای REST آمادهٔ اتصال به Django هستند.

```bash
# وقتی بک‌اند آماده شد:
flutter run \
  --dart-define=USE_MOCK_API=false \
  --dart-define=API_BASE_URL=https://your-server.com/api
```

برای تست mock می‌توانید با هر شماره موبایل و رمز حداقل ۶ کاراکتر وارد شوید. نشست کاربر بعد از ورود ذخیره می‌شود و در اسپلش بازیابی می‌گردد.
